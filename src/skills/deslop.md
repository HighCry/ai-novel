# 网文去AI味

AI 味不是语法错误，是风格问题：过于工整、过于圆滑、解释得太充分。去 AI 味是把文字从“完美”拉回具体、自然、可读，不是重写。

## 写作规则

1. 镜头钉在视角人物身上：只写他此刻看到、听到、做的和想的。不解释因果，不剧透（殊不知、她不知道的是、多年以后），不替读者下结论或总结意义（这意味着、终于明白、这一刻），也不插作者式的断语（“神仙难救。”“全程耗时两息半。”“所有死角推演完毕。”）。
2. 情绪落到动作、台词、物件和后果上。关键情绪不写“感到、意识到、明白”；低强度的过场情绪可以一笔直写（他有点烦），不必处处外化。
3. 叙述以逗号长句为主：一句用逗号串起两三个动作或信息，逗号之间八到十二个字，整句二三十字。短句只在冲突、反转、爆点处用来重拍，用完回到长句。不要通篇碎句像提纲，也不要一长一短机械交替。
4. 段落按镜头和戏剧单元断开：同一个镜头里的几个动作写在一段，不要一句一段地切镜头；拟声词不单独成段（“噗。”“咔嚓。”），并进动作句里；同一个瞬间也不要拆成先写发生、再写感知、再写身体反应的好几段。
5. 对话像人说话：口语、有省略、不同人语气不同。对话标签少用，多用动作或上下文引出，不写“说道、沉声道、淡淡道”。
6. 比喻一章最多三五个，优先白描；要用就用贴合角色身份的生活化比喻，不用“如潮水般、犹如寒冰、如天罚降世”这类万能比喻，也不要连着用。
7. 强调词不要堆：极其、猛地、死死、狠狠、疯狂、彻底、精准，一章里各用一两次就够，让动词自己用力。数字只在推动剧情时写，不要处处精确到几寸、几息、几丈。
8. 这些句式一次都不要用：“不是A，而是B”；“没有A，只有B”；“……，带着一丝/一抹……”；“声音不大，却带着……”“听不出半点波澜”；“取而代之的是”；“他知道……/她明白……”；“终于明白、这才意识到、从这一刻开始、才刚刚开始、命运的齿轮/棋局”；三连排比。
9. 这些词基本不用：仿佛、犹如、宛若、一丝、一抹、些许、不禁、深吸一口气、眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩、指节泛白、心中一动、心头一震、心中暗道、不由得、不容置疑、不易察觉、显而易见、毫无疑问、深邃、凛冽、不由自主、情不自禁、话锋一转；“缓缓、微微、轻轻、淡淡”每千字合计不超过三个。
10. 叙述里不用破折号“——”和省略号制造停顿，犹豫和打断用动作或短句表现；台词里人物喘息、哽咽、结巴时的省略号可以保留。
11. 章末用动作、对话或一个具体的悬念收住，不写感悟、总结、升华，也不写“更大的风暴即将来临”式的预告。

## 修订流程

### 核心原则

1. 改“怎么说”，不改“说什么”：剧情、人设、事件顺序、伏笔一律不动；境界等级（炼体九重圆满）、物品和功法的全名（六角天平砝码）、地点细节（卧房还是书房）、数量（三百斤、两千灵石）、人名地名都属于设定，一个字都不改，也不要连同所在的句子删掉；不新增原文没有的动作、情节、台词和人物关系。
2. 改最少的字：能改一个词就不改一句，能删一句就不重写一段；没有问题的句子原样保留。
3. 不整段删除，台词一句都不删（可以改得更口语）。删之前确认这句话没有承担伏笔、钩子、人物特征、情绪承接或因果信息；有就改写，不删。
4. 删减有上限：AI 味轻度时不超过原文的 15%，中度不超过 25%，重度不超过 35%。修订稿也不要比原文长，变长了多半是补写了原文没有的东西。

### 三遍法（按顺序，只动有问题的地方）

**第一遍：去泛化和套话**（大部分 AI 味在这一遍解决）

- 删掉或替换写作规则第 8、9 条里的句式和词。
- 抽象情绪句（一丝悲伤涌上心头）改成角色此刻的一个动作、一句话或一个具体后果；不要换成另一个套话。
- 解释腔、上帝视角、替读者下结论的句子直接删；作者式的断语（神仙难救。所有死角推演完毕。）删掉或改成角色此刻的动作。确实需要的信息，改成角色能看到、碰到、被迫处理的东西。
- 比喻太密时只留一两个最有用的，其余改成直写；不要把旧比喻换成新比喻（如天罚降世改成如雷霆坠地不算改）。
- 堆在一起的强调词（极其、猛地、死死、狠狠、精准）删掉大半。
- 单独成段的拟声词并进前后的动作句；一句一段切得太碎的，同一个镜头里的并成一段。合并时只用原文已有的动作和信息，不要为了把句子写长补写新的。
- 章末的总结、感悟、预告删掉，用最后一个动作或一句对话收住。
- 三连排比只留最有力的一条。
- 同一个瞬间被拆成好几段的，合并成一段连续的画面。

**第二遍：去书面腔**

- 小说里出现“机制、体系、逻辑、进一步、从而、因而、诚然、与此同时、于是乎”，换成日常说法或直接删。
- 对话里的书面语改成口语（我认为此事不妥 → 我觉得不靠谱）。
- 堆砌的形容词和定语改成白描（美丽动人的笑容 → 她笑了）。

**第三遍：回自然感**

- 连续三句以上同一个主语开头，换个开法：动作、环境或对话。
- 调节奏：铺垫和日常用逗号长句，冲突和反转处骤短；不要整段一个长度。
- 不同人物说话要能区分开。泛泛的描写可以换成一个这个场景独有的具体细节，但这是替换，不是另加：不要补写原文没有的动作、细节和台词。

### 不要矫枉过正（这些同样是 AI 味）

- 不要把句子都压成三五个字的短句，读起来像电报或提纲；铺垫、过渡和日常动作保留“了、的、就、已经、之后”这些自然的连接。
- 不要用同义词轮换来应付：把“缓缓”换成“慢慢”不算改。同一种替换也不要反复用（每处都“垂下眼”、每个动作都接“了一下”），替换本身会变成新的模板。
- 每个动作后面都补一个小反应（扯了下、停了一下、拍了两下）也是模板，合并或删掉。
- 不要硬加口误、脏话和倒装，不要为了凑对话比例把叙述改成台词，不要强制每句换行。
- 台词里人物断断续续的喘息、哽咽和结巴是有功能的，省略号保留，不要把濒死的人改得说话利索。

### 改写范例

- 他感到一阵紧张，心跳不由自主地加快了 → 他攥紧纸杯，水洒出来一些。
- 一丝悲伤涌上心头，她的眼中闪过泪光 → 她低头搅着咖啡，搅了很久。
- 他的瞳孔微微收缩，显然没有想到会听到这样的话 → 他张了张嘴，没说出话。
- 她声音不大，却带着不容置疑的力量 → “放下。”她说。
- 他不是冷漠，而是绝望 → 他把通知单折好，塞进最里层的口袋。
- 阳光透过窗帘的缝隙洒进来，在地板上投下斑驳的光影，空气中弥漫着淡淡的花香 → 下午三点，客厅里只有钟在走。
- 这一刻，一切都变了。她知道，她的人生将翻开新的一页 → 她关上门，没回头。
- “好的。”他沉声说道 → “好的。”他把门卡塞回口袋。
- 林父低着头，左手压住文书，右手拿笔。（另起一段）手从肘到腕都在抖。（另起一段）笔尖停了停，写了一横，又停 → 林父左手压着文书，右手拿笔往纸上落，笔尖一碰纸就偏了，从肘到腕止不住地抖，那一横斜着拖了出去。

### 收尾自检

- 剧情、人名、数字有没有被改动？有就改回来。
- 有没有整段消失？有就换回改写后的版本。
- 从头连读一遍：像人在讲故事，还是像提纲？像提纲就把过渡句并回去。
